# HOME COMPASS · 2028 신혼집 마련 대시보드 (1차 버전)

실제 사용할 수 있는 **개인용 정적 웹앱**입니다. 오늘 기준 자금, 매달 저축액, 퇴거일 예상 자기자본, 가정한 대출 조건(LTV/DSR/금리/만기), 관심 매물의 가격 변경, 관심 지역 평가, 공개 정책 뉴스 및 (API 연결 시) 아파트 실거래가를 한곳에서 확인합니다.

## 1. 당장 사용하기

1. 압축파일을 해제하고 `index.html`을 브라우저로 엽니다. 인터넷이 없어도 **자금계산과 관심 매물/지역 관리 기능**은 사용됩니다.
2. 우측 상단 `계획 설정`에서 **퇴거일, 종잣돈, 월 저축액, 목표 자기자본**을 입력하세요. 자금·저축 메뉴에서 보증금 반환액, 비상금, 세후 수익률을 보완합니다.
3. `대출·구매력`에서 부부 세전 연소득, 적용할 LTV와 DSR, 실제 은행 금리, 부대비용, 별도 주담대 한도를 입력합니다. **기본 숫자(예: DSR 40%, 금리 4.5%, 비용 2.5%)는 단순 시뮬레이션 초기값이지 현행 제도 확정값이 아닙니다.**
4. `관심 매물`에서 네이버부동산·호갱노노 링크를 추가하고 호가를 수정하면 변경 이력이 자동 쌓입니다. 지역·개발 화면은 직접 확인한 사업 진척도 기준으로 5개 평가요소를 채웁니다.
5. `백업 내려받기`를 주기적으로 사용하세요. `백업 복원`으로 다른 기기에서 가져올 수 있습니다.

### 저축 입력 규칙

- `현재 종잣돈`에는 **지금 이미 모은 총액**을 넣습니다.
- `저축 원장`에는 그 시점 **이후 추가 납입/인출만** 입력합니다. 이미 종잣돈에 반영한 자금은 중복 입력하면 안 됩니다.
- 예측 시 앞으로 오는 달의 1일마다 설정된 월 저축액을 납입하는 것으로 가정합니다. 이자 발생도 단순 월복리 가정이며, 투자손익이나 세제 차이는 별도 반영되지 않습니다.
- 현재부터 퇴거일까지 보증금이 반환되지 않는다면 `퇴거 시 반환받을 보증금`에 입력하고, **비상금은 별도로 남깁니다**.

## 2. 실제 매일 업데이트하도록 배포하기 (무료 운영 기반)

이 파일만 더블클릭해서 여는 **로컬 버전 자체는 자동으로 데이터를 인터넷에서 가져오지 않습니다**. 자동 갱신에는 온라인 실행 환경이 필요합니다. 아래 설정을 마치면 `GitHub Actions`가 한국시간 기준 매일 약 오전 9:10에 공개 정보를 수집하고 `GitHub Pages`가 동일한 웹 화면을 제공합니다. GitHub의 지연, API 오류, 서비스 중단, 네트워크 차단으로 일정이 지연되거나 누락될 수 있습니다.

1. GitHub에서 새 저장소를 만듭니다. 공개 웹페이지로 볼 계획이면 **public 저장소**로 만듭니다. 이 폴더 내용을 저장소 루트에 업로드합니다 (`.github/workflows` 경로 포함).
2. 저장소에서 `Settings > Pages > Build and deployment`의 `Source`를 `Deploy from a branch`로, `Branch`는 `main / (root)`로 설정합니다.
3. `Actions > Daily public housing data update > Run workflow`를 수동으로 한 번 실행해 첫 피드를 생성합니다. 이후 UTC 00:10에 매일 실행되도록 설정되어 있습니다. Actions에 쓰기 권한이 제한되면 설정에서 workflow 권한을 `Read and write permissions`로 활성화합니다.
4. 관심 지역 **아파트 매매 신고 실거래가**도 조회하려면 공공데이터포털에서 아래 API에 활용 신청해 받은 **일반 인증키(Decoding 원본값)**를 저장소 `Settings > Secrets and variables > Actions > New repository secret`에 `MOLIT_SERVICE_KEY`라는 이름으로 넣습니다. `data/regions.json`에 조회할 시군구 코드 5자리와 이름을 추가합니다. 초기 `11110`은 **종로구 예시**, 사용자의 관심 지역을 뜻하지 않습니다.
5. **선택 사항:** AI 제목 요약까지 사용하려면 OpenAI API의 **별도 유료 API 키**를 `OPENAI_API_KEY` 시크릿으로 등록합니다. 추가로 repository variable `OPENAI_MODEL`을 지원되는 모델 이름으로 설정할 수 있습니다. ChatGPT Plus 구독과 API 비용은 별도입니다. 키가 없으면 AI 문장 요약 없이 제목 자동 수집만 실행됩니다.

주의: 공개 저장소에 개인 저축 내역, 잔액 백업, 은행 계좌, 인증키를 **커밋하지 마세요**. 금융정보는 브라우저 `localStorage`에만 저장되며, 브라우저를 초기화하거나 다른 기기를 사용하면 자동으로 동기화되지 않습니다. 같은 링크를 타인에게 공유해도 해당 개인의 금융 값은 보이지 않습니다.

## 3. 갱신되는 항목과 아직 자동화되지 않은 항목

| 구분 | 1차 버전에서 지원하는 범위 | 조건/한계 |
|---|---|---|
| 저축 및 누적액 | ✅ 매번 화면을 열 때 계산 | 실제 납입/잔액은 직접 기록 |
| 퇴거일 예상 자산 | ✅ 자동 시뮬레이션 | 월 저축·수익·보증금 반환 가정 |
| 매수가 상한/원리금 | ✅ 자동 시뮬레이션 | LTV·DSR·금리·세금비 등 실제 조건 확인 필수 |
| 금융위원회 발표 | ✅ GitHub Actions 설정 후 매일 RSS 수집 | 일부 소스는 일시 장애 가능 |
| 국토부·서울시 뉴스 | ✅ 공개 도메인 뉴스 RSS 탐색 | 기사 제목 기반, 원문으로 시행 여부 검증 |
| 은행 금리 변화 | ⚠ 공시 관련 제목 수집 및 금리 수동 입력 | **은행별 실시간 적용 금리 숫자 자동비교 아님** |
| 국토부 아파트 매매 실거래 | ✅ 인증키+지역코드 설정 후 조회 | 신고 지연, 해제거래 제외 노력, API 제한 가능 |
| 네이버부동산·호갱노노 매물 | ⚠ 원문 링크 보관 및 가격 수동 업데이트 | **포털 실시간 호가·매물 수 자동 수집 아님**; 공식 데이터 이용권한 필요 |
| 도시계획 수혜지역 | ⚠ 발표 제목에서 지역명 후보 자동 추출 + 수동 평가 | 보도 빈도는 가격 전망 아님, 발표/확정/착공 구분 및 실거주·공급 확인 필요 |
| 공개뉴스 AI 요약 | ✅ OpenAI API 연결 시 생성 | 제목 기반 요약, 원문 검증 필요 |

## 5. 기본 기술 구조 및 확장

- UI: 단일 `index.html`, 웹브라우저에만 금융정보 보관
- 공개 데이터: `data/daily.json` + 브라우저에서 바로 읽는 `data/daily.js`
- 수집기: `scripts/update_data.py` (Python 표준 라이브러리만 사용)
- 스케줄: `.github/workflows/daily-update.yml`
- 실거래 조회지역: `data/regions.json`

**다음 개발 단계:** 사용자별 로그인/암호화된 클라우드 백업, 실제 매물 데이터 라이선스 연동, 은행별 공시금리 공식 데이터 연동, 분기별 도시계획 사업단계 확인, 실제 대출 사전심사 반영, 교통·직장 위치 기반 지역 평가. 이 단계들은 아직 구현되지 않았습니다.

## 6. 로컬 수집 테스트

```bash
python scripts/update_data.py
python -m http.server 8000
```

`http://localhost:8000`을 열면 갱신된 공개 정책 피드를 볼 수 있습니다. API 키가 없다면 뉴스만 수집합니다. 데모 키·계정·실제 대출 데이터는 포함하지 않았습니다.
